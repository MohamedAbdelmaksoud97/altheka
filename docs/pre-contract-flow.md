# مسار ما قبل التعاقد

## البداية

1. ينشئ العميل حسابًا ويؤكد بريده، ثم تظهر شاشة الانتظار.
2. يبحث مدير العملاء عن الحساب.
3. ينشئ المدير طلب الخدمة ويربطه بالعميل الرئيسي.
4. يسجل الاستقبال والاجتماع ونوع الخدمة والمسار المتوقع ويطلب المستندات.
5. يرفع العميل أو الموظف المصرح المستندات إلى Storage الخاص.

لا يملك العميل RPC أو سياسة RLS لإنشاء `service_requests`.

## الدراسة والعرض

1. يختار مدير العملاء المكلف المؤهل داخل الإدارة والمسار.
2. يقدم المكلف الدراسة خلال 24 ساعة، مع تمديد إداري موثق إلى 48 ساعة.
3. دراسة التقاضي لا يعتمدها إلا من يملك `studies.approve_litigation`، ودراسة
   التركات لا يعتمدها إلا من يملك `studies.approve_estates`.
4. الإعادة للتعديل تنشئ دورة مراجعة جديدة ولا تمحو التسليم السابق.
5. ينشأ العرض الفني والمالي بإصدار مستقل، وصلاحيته الافتراضية ثلاثة أيام تقويمية.
6. يسجل قبول العميل أو التخفيض أو التفاوض أو الرفض كحدث دائم.
7. التخفيض أو التفاوض ينتج إصدارًا جديدًا ولا يعدل العرض المرسل.

## العقد والتحويل

- كل تعديل ينشئ `contract_version` جديدًا وبصمة SHA-256 جديدة.
- القبول الإلكتروني Append Only للنسخة المحددة ويحفظ المستخدم والوقت وIP
  وUser Agent والإقرار الصريح.
- يمكن رفع نسخة موقعة يدويًا وربطها بالإصدار.
- لا تعدل نسخة وافق عليها العميل، والإصدار الجديد يحتاج موافقة جديدة.
- لا يتحول الطلب إلى مشروع إلا بقبول صالح للإصدار الحالي أو نسخة موقعة معتمدة.
- التحويل Idempotent وينشئ رقم العقد والمشروع والفريق والمكلف الرئيسي وقناتي
  المحادثة ويبدأ مرحلة التهنئة من القالب المناسب.

## الحالات

`received` → `linked` → `collecting_documents` → `assigned` →
`study_pending_approval` → `study_returned` أو `study_approved` →
`proposal_sent` → `discount_requested` أو `negotiating` أو
`proposal_accepted` أو `proposal_rejected` → `contract_sent` →
`contract_accepted` أو `signed_copy_received` → `converted_to_project`.

## الأمان

- كل تغيير يمر عبر RPC أو Server Action يتحقق من Permission والنطاق.
- لا تسمح الدراسة بمعتمد من الإدارة الأخرى.
- لا يكشف استعلام العميل الحقول الداخلية أو الفريق الكامل.
- كل إسناد واعتماد ونشر وقبول وتحويل يسجل في Audit.
- الطلبات القديمة تبقى `legacy` ولا يبدأ لها Workflow v2 تلقائيًا.
