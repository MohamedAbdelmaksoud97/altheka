# مصدر الحقيقة وسجل القرارات

تاريخ الاعتماد: 2026-07-29

## ترتيب الأولوية

عند التعارض تطبق المصادر بالترتيب الآتي:

1. `docs/references/خارطة_السير_لادارة_التقاضي_اخر_تعديل_1_1.docx`
2. `docs/references/خارطة سير تصفية التركات .pdf`
3. التوجيه التنفيذي المعتمد بتاريخ 2026-07-29.
4. القرارات والافتراضات السابقة في `docs`.
5. التنفيذ البرمجي الحالي.

مراحل العمل والمدد والأطراف والإجراءات الدورية والتقارير والإقفال الواردة في
المرجعين ملزمة. إذا تعذرت قراءة خانة إسناد، يبقى الإجراء ولا يحذف، ويوسم
`Needs Operational Confirmation` وتظل قواعد إسناده قابلة للتعديل في القالب.

## قاعدة الاستبدال الإلزامية

النظام هو المصدر الرسمي الوحيد للبيانات والمستندات والمحادثات وسير العمل:

- مجموعة WhatsApp تستبدل بقناة عميل وقناة داخلية مع المشاركين والقراءة والمرفقات
  والسجل الدائم.
- Google Drive يستبدل بـ Supabase Storage خاص، وإصدارات مستقلة، وروابط موقعة،
  وقواعد رؤية، وسجل تنزيل ونشر وسحب.
- المحامي الذكي يستبدل بالمشروع وWorkflow والمراحل والمهام والمواعيد والإجراء
  القادم والتقارير والأرشيف داخل النظام.

لا ينشأ تكامل أو مهمة لتكرار الإدخال في هذه الأدوات. تظل ناجز والبورصة العقارية
وإيجار والمنصات الحكومية والقضائية إجراءات خارجية ينفذها الموظف ويوثق نتيجتها
ومستنداتها داخل النظام.

## الانحرافات المعتمدة عن المرجعين

- اعتماد المرافعة المتعارض افتراضيًا لمدير التقاضي. يظهر المدير التنفيذي فقط
  في القضايا المتوسطة أو الكبرى بشرط صريح، وفي إجراءات الإقفال والتحصيل التي
  نص عليها المرجع.
- مدة خمسة أيام في المرحلة التمهيدية للتركات هدف لحزمة المستندات كاملة وليست
  خمسة أيام لكل مستند.
- تبقى مهمة تسجيل أصل العقد الورقي وموقع حفظه، ولا يعد الأرشيف الورقي مصدر
  بيانات موازيًا.
- تفسر عبارة «فريق التقيّة» بأنها «فريق التصفية».
- المطالبة بديون التركة ذات خانة المكلف الفارغة تحال إلى مسار تقاضي التركة.
- WhatsApp وGoogle Drive والمحامي الذكي مستبعدة وفق قاعدة الاستبدال أعلاه.

## حماية البيانات الحالية

- لا Drop ولا Purge ولا إعادة كتابة للقوالب المنشورة في Sprint المواءمة.
- المشاريع والطلبات وWorkflow Instances الحالية توسم `legacy` وتبقى على v1.
- قوالب v2 اجتازت فحص المواءمة ثم نشرت في Migration
  `20260729132005_operational_project_interfaces`. لا يعاد تشكيل أي Instance قديم،
  ولا يبدأ المشروع الجديد إلا عبر عملية خادمية مصرح بها.
- أي قيمة لا يمكن استنتاجها بأمان تظل `NULL` ولا تستبدل بتخمين.
- كل Backfill قابل لإعادة التشغيل ويكتب أثره في Audit Log أو سجل Migration.
