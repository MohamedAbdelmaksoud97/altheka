# دليل عرض النظام

تاريخ التجهيز: 2026-07-29

## قبل العرض

1. شغّل `npm run dev`.
2. افتح `http://127.0.0.1:3000`.
3. استخدم حساب Super Admin من `INITIAL_SUPER_ADMIN_EMAIL`.
4. حساب العميل التجريبي هو القيمة في `DEMO_CLIENT_EMAIL`.
5. تحفظ كلمة مرور العرض في `DEMO_CLIENT_PASSWORD` ولا تكتب في المستودع.

يمكن إعادة تجهيز البيانات دون تكرار:

```powershell
npm run seed:demo
```

## مسار عرض الموظف

1. افتح لوحة العمليات، ثم المشاريع.
2. افتح `DEMO-LIT-2026-001`.
3. اعرض التهنئة المكتملة والتأسيس والتقييد الجاري.
4. افتح المرافعة والجلسات، ثم بطاقة القضية والإجراء القادم والجلسة ومهام التحضير.
5. افتح المستندات والمحادثة الداخلية وقناة العميل.
6. افتح `DEMO-EST-2026-001`.
7. اعرض الورثة والأنصبة، ثم الأصول الثلاثة الموجودة في مراحل مختلفة.
8. افتح مشروع أصل مستقل وفرق الحصر والتهيئة.

## مسار عرض العميل

1. ادخل بالحساب التجريبي.
2. افتح مشروع التقاضي من «ملفك القانوني».
3. اعرض المرحلة المبسطة ومسؤول التواصل.
4. اعرض الرسالة الافتتاحية والمستند المنشور.
5. وضح أن العميل لا يستقبل بيانات الفريق أو Workflow أو بطاقة القضية أو الورثة.

## تحقق العرض

```powershell
npm run lint
npm run typecheck
npm test
npm run build
```

اختبار العرض الحي:

```powershell
npm run test:demo-live
```

لقطات العرض تحفظ محليًا في `artifacts/screenshots` ولا تعد جزءًا من بيانات
المشروع القانونية.
