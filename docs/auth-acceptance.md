# قبول Auth ومصفوفة الوصول

آخر تحقق حي: 2026-07-29

## إعداد المشروع

- مشروع Supabase: `rsponlicurferszdlcej`
- Site URL للتطوير: `http://localhost:3000`
- Redirect URLs:
  - `http://localhost:3000/auth/confirm`
  - `http://127.0.0.1:3000/auth/confirm`
- تأكيد البريد مفعل.
- الحد الأدنى لكلمة المرور 8 أحرف مع حروف كبيرة وصغيرة وأرقام.
- MFA وSMS معطلان في الـMVP.
- مهلة إعادة إرسال البريد 60 ثانية، وEmail OTP مكون من 8 أرقام.
- أول Super Admin يُقرأ من `INITIAL_SUPER_ADMIN_EMAIL`، ولا يوجد بريد ثابت داخل الكود.

## نتائج الاختبار الحي

- نجح تسجيل موظف من واجهة `/register/staff`.
- أنشئ ملف الموظف بحالة `pending_staff_approval` وطلب تفعيل بحالة `pending`.
- مُنع الموظف المعلق من قراءة قوالب Workflow.
- نجح تسجيل عميل من واجهة `/register/client`.
- أنشئ ملف العميل بحالة `client_waiting`.
- نجح تأكيد البريد للحسابين.
- نجح Super Admin في تفعيل الموظف واختيار الإدارة والمسمى والدور عبر معاملة PostgreSQL.
- تحول الموظف إلى `active_staff`.
- نجح دخول الموظف وتحويله إلى `/workspace`.
- نجح ربط العميل بملف عميل ومشروع وتحويله إلى `active_client`.
- نجح دخول العميل وتحويله إلى `/client`.
- مُنع الموظف العادي من استدعاء إجراء اعتماد الموظفين.
- عُطلت حسابات الاختبار بعد القبول بدل حذفها.
- نجح Bootstrap مرتين دون تكرار الحساب أو دور Super Admin.

## التشغيل

الاختبارات اليومية الآمنة:

```powershell
npm run test:e2e
```

اختبار Auth الحي ينشئ حسابات ويرسل بريدًا، لذلك لا يعمل ضمن الحزمة اليومية:

```powershell
npm run test:auth-live
```

توجد كلمة مرور Bootstrap المؤقتة في `.env.local` فقط. يجب تغيير كلمة مرور المدير من حسابه ثم حذف `INITIAL_SUPER_ADMIN_PASSWORD`.
